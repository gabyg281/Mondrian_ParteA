# Parte A — Reprodução fiel

Nesta primeira parte do trabalho, defini o fundo como preto e utilizei o Adobe Illustrator para mapear as coordenadas exatas dos quadrado, alterando-os para o p5.js através da função quad(). 

Para quebrar o aspeto digital e tentar simular a textura e aspeto mais envelhecido da tela original, desenvolvi um sistema gerativo de textura, um algoritmo que desenha milhares de minúsculos traços aleatórios (horizontais e verticais) com uma opacidade muito baixa. A sobreposição impercetível destas linhas claras e escuras cria um ruído visual na tentativa de imitar o máximo possível a trama de tecido.
